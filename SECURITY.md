# Security Policy

## Reporting

Do not disclose suspected vulnerabilities in public issues. Use GitHub's private security-advisory workflow for this repository.

Include only the minimum information required to reproduce the concern. Never include credentials, personal data or private environment details.

## Supported scope

The actively maintained line is `main`. This repository is an engineering snapshot and does not claim a production deployment.

Security fixes require review, tests, dependency audits and applicable image scans. Critical findings block release.
